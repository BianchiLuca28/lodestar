# LangGraph for all AI orchestration

Every LLM workflow (message parsing, plan agent, chat with RAG) is a LangGraph graph from the first AI feature, using langchain-ollama. Chosen for job-market relevance: in an April 2026 analysis of 534 agentic-AI job ads, LangChain appeared in 34% and LangGraph in 22%, PydanticAI in 2.4%. The user prefers learning the framework by building over a framework-free first version.

## Considered Options

- Raw OpenAI-compatible calls first, framework later: more insight into internals, slower to a working app.
- PydanticAI: clean and typed, but rarely asked for by employers.
