# The pension fund is out of scope

Lodestar does not track the Cometa supplementary pension: no account, no value, no net-worth contribution, and the agent never asks about it. Its value is hard to obtain, it sits outside the four pillars, and nothing in the plan acts on it before 2033.

## Considered Options

- A manually valued account outside the pillars: needs periodic input from the fund's website for a number that drives no decision.
