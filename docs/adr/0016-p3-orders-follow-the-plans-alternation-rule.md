# P3 bond orders follow the plan's alternation rule

The finalized plan (31/10/2026) fixes how pillar 3 buys: one order a quarter, alternating Italian and German government bonds on the furthest pair that matures on or before the expected house date, BTPs in whole lots of €1,000 nominal, maturities reinvested in the same country. Lodestar computes that pick in code and the agent only explains it. Gross yield is shown when bonds are compared, because Borsa Italiana's net yield overstates bonds bought below 100.

## Considered Options

- Rank policy-allowed candidates by net yield to maturity (ADR 0008's original mechanism): it would second-guess a rule the user already decided, and the alternation exists to hold both countries, not the best yield.
